# Directorio progress

Este directorio concentra el historial de quizzes, progreso por libro y lógica de reset por usuario.

## Archivos y Funcionalidades

*   **[quiz-progress.php](quiz-progress.php)**: Crea la tabla de intentos, registra puntajes por sesión, calcula avance del libro y habilita el reset solo cuando todos los quizzes fueron completados.
