# Directorio book-templates

Este es el repositorio canonical de `Book Templates`.

Un `Book Template` debe describir al menos:

- `id`
- `kind: "book-template"`
- `name`
- `description`
- `visibility` (`public` o `private`)
- `source` (`builtin` o `custom`)
- `settings` con la configuración editorial completa

Opcionales:

- `preview` para la tarjeta o carrusel de selección
- `sample_chapters` para sembrar el libro con contenido de ejemplo

El archivo de referencia es `default-classic.json`.
