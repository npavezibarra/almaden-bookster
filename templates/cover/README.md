# Directorio Cover Templates (`templates/cover/`)

Este directorio contiene la plantilla del diseñador de portadas de libros.

## Archivos y Funcionalidades

- **`cover-app.php`**: Renders la aplicación de diseño interactivo para la portada de los libros (Bookster Cover Editor). Permite posicionar textos, cambiar colores, subir imágenes y estructurar la contraportada, lomo y portada de impresión.
