# Directorio Shell Templates (`templates/shell/`)

Este directorio contiene las app pages internas que comparten el shell visual de Almaden.

## Archivos y Funcionalidades

*   **[shell-home-app.php](shell-home-app.php)**: home del shell con accesos rápidos a las secciones internas.
*   **[reading-stats-app.php](reading-stats-app.php)**: panel personal de lectura con resumen de highlights, quizzes y actividad reciente.
*   **[access-denied-app.php](access-denied-app.php)**: pantalla común para acceso restringido dentro del shell.
