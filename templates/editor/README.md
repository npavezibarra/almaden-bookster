# Directorio Editor Templates (`templates/editor/`)

Este directorio contiene las plantillas PHP relacionadas con la interfaz principal del editor de libros (Content Editor) y sus modales de configuración.

## Archivos y Funcionalidades

- **`editor-app.php`**: Plantilla principal que renderiza el contenedor y las zonas de la aplicación de edición de libros.
- **`editor-settings-modal.php`**: El modal global de configuración del formato de impresión y visualización del PDF.
- **`chapter-settings-modal.php`**: El modal de configuración específico a nivel de capítulo.
- **`chapter-settings-normal.php`**: El contenido y formulario para un capítulo de tipo normal.
- **`chapter-settings-toc.php`**: El formulario de configuración para la Tabla de Contenidos.
- **`settings-tabs/`**: Pestañas de configuración individuales para el modal de maquetación (páginas, tipografías, encabezados/pies, capítulos, créditos, ebooks).
