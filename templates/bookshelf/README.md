# Directorio Bookshelf Templates (`templates/bookshelf/`)

Este directorio contiene la plantilla de la estantería pública.

## Archivos y Funcionalidades

- **`bookshelf-app.php`**: Renderiza la estantería de libros públicos en la parte frontal de WordPress, cargando la cuadrícula con las portadas y accesos directos al lector.
